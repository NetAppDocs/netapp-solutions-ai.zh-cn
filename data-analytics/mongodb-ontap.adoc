= TR-4492：NetApp ONTAP 上的 MongoDB
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


Karthikeyan Nagalingam， NetApp

[role="lead"]
本参考架构介绍如何在 NetApp ONTAP 上搭配 VMware vSphere 部署和保护虚拟化分片 MongoDB 数据库。该架构可为 MongoDB 团队提供一致的低延迟性能、用于备份、恢复、开发/测试和 QA 的即时空间高效副本，以及向云端 ONTAP 进行灾难恢复的能力。横向扩展 NetApp AFF 阵列托管 MongoDB 虚拟机 （VM） 和数据库。NetApp SnapCenter 管理 MongoDB 环境的 NetApp Snapshot 副本，SnapMirror 将其复制到云端。本报告还介绍了两个客户使用案例：通过 MongoDB Atlas 提供 NetApp Digital Advisor 服务，以及使用 Ops Manager 进行企业级 MongoDB 备份和恢复。

MongoDB 是一个流行的开源、横向扩展的 NoSQL 数据库。它为需要低读取和写入延迟、高可用性和高级数据管理的现代数据湖应用提供支持。MongoDB 的关键用例包括实时分析、产品目录、内容管理和移动应用程序。

该 NetApp 解决方案为部署任务关键型 MongoDB 应用程序提供了以下主要优势：

* 与直连存储相比，它具有可预测的高性能和始终如一的低延迟，为基于 MongoDB 构建的最苛刻的分析应用程序提供出色的响应时间。
* 内联重复数据删除和压缩带来的内联效率，最大限度地减少了 MongoDB 所需的闪存存储。
* 即时、节省空间且经济高效的数据库克隆，无需购买新存储即可快速设置开发/测试或 QA 环境。
* 基于节省空间的 NetApp 快照技术进行备份和恢复，并远程复制到云。
* 来自纵向扩展和横向扩展 AFF 阵列的可扩展性，该阵列可随 MongoDB 模块化扩展存储。
* 具有高可用性的无中断操作，提供最大的正常运行时间和一致的性能，特别是在驱动器故障期间。
* 在异构环境中部署 MongoDB，提供灵活性和额外的成本节约。
* 通过 NetApp SnapCenter 实现备份、还原和克隆的单一界面管理。
